# 一、论文内容规范

## 1.1 Non-fiction Writing

论文中不要出现没有什么意义的废话。

> 例子：
>
> - 论文中的 *in order to* 可以改为 *to*。
> - 论文中不要出现 *have, do* 等没有具体意义的词。
> - 论文中的 *The function has two parameters.* 这句话可以改为 *There are two parameters that ... We generate test case for the two parameters of the functions.* ，这样修改使得这句话的信息密度更高。

## 1.2 不杂不凑

论文中的分点要做到不杂不凑，要做到每一个点都能堵住漏洞。
- “不杂”要求避免杂乱无章的信息，要求要点间有明确的逻辑关系（递进、因果等），同时要避免冗余。
- “不凑”要求论文要点要言之有物，要做到论文中的每一个部分都是整体论文链条中不可或缺的一环。

# 二、论文撰写规范

## 2.1 通用规范

- 论文中首次出现生词的地方时一定要有解释。
    > 例子：
    >
    > *集合 S 和 T 的乘积映射到 V 上 S x T: V。* 这句话对生词 *S T V* 进行了解释。
- 论文中要确保没有语法错误，可以将论文内容复制到 Word 中，利用 Word 内置的语法检查检验是否存在语法错误。
- 参考文献：
  - 人名不要出现错误，DBLP 网站的引用信息较为准确，引用后最好人工再确认。
  - [C] 和 [J] 为国标参考格式，如果参考文献格式没要求，则不需要写。
  - 参考文献的格式应当统一，例如姓名的顺序、是否大小写、是否缩写等。
  - 尽量不要使用 et al.，尽量列出所有作者，除非参考文献格式要求最多只列几个作者。
  - 参考文献为链接时需要说明链接是什么，同时链接尽量使用 http。例如 [1] OpenCV, http://opencv.org/
- 论文中不要出现四级标题，如 2.1.1.1。
- 中英文编号：中文中应该使用全角括号“（1）”，英文中应该使用半角括号“(1)”。
- 编号“①”应当在行内使用。
- 段落格式应当为两端对齐。

## 2.3 英文规范

- 标题中冒号后的第一个单词的首字母需要大写，或者所有实词的首字母均大写。例如 *GenProg: A genetic method for automatic software repair* 或 *GenProg: A Genetic Method for Automatic Software Repair*

# 三、写作工具

常用的写作工具包括 Word 和 LaTeX。当使用 LaTeX 进行论文撰写时，通常使用 Overleaf 进行多人协作，同时需要一份本地的 LaTeX 环境，以应对 Overleaf 中存在的 Bug。

## 3.1 审阅

- Word：使用审阅模式进行审阅和修改。
- LaTeX：使用 Overleaf 进行多人协作，同时使用以下命令进行审阅和修改。
